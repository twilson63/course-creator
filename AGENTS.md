# agents.md – Course‑Creator Project Overview

**Repository:** https://github.com/twilson63/course-creator

## Purpose
The *OpenCode Course Creator* is a TypeScript‑based CLI that generates interactive video‑course pages from a JSON course description and step‑by‑step markdown files. It stitches You‑Tube (or other video) segments with instructional content, produces a self‑contained HTML output, and can deploy the result to ZenBin.

## Key Features
- **JSON schema** defining course meta, steps, checkpoints, and resources.
- **Markdown step files** for detailed instructions and hints.
- **Video segment handling** – start timestamps (and optional end timestamps) for YouTube, Loom, Vimeo, Descript.
- **CLI commands** (`build`, `--standalone`, `--watch`).
- **Deploy script** — curl POST to ZenBin with Base64‑encoded HTML.
- **Examples** include a full `scout‑transcripts` demo.

## Architecture
- `src/cli/` – entry point (`index.js`) parses arguments and runs the build pipeline.
- `src/core/` – core logic: parsing JSON, reading markdown, generating HTML, handling video timestamps.
- `src/template/` – HTML templates used for the final page.
- `src/types/` – TypeScript interfaces for the JSON schema.
- `tsconfig.json` – TypeScript compilation settings.

## Build / Run Steps (from README)
```bash
npm install            # install deps
npm run build          # compile TS to dist/
node dist/cli/index.js build course.json -o output/index.html --standalone
```
Deploy to ZenBin via the curl command shown in the README.

## Extensibility
- Add new video providers by extending `src/core/video.ts`.
- Create custom HTML themes in `src/template/`.
- Integrate with other AI agents (OpenCode, Claude) by feeding the JSON schema and markdown files.
