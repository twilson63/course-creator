# What We're Building

In this course, you'll learn how to create an end-to-end automation for processing call transcripts using ScoutOS.

## The Big Picture

We're going to build a system that:

1. **Receives** a webhook when a new call transcript is available
2. **Fetches** the transcript from an external service using code
3. **Summarizes** the call and extracts key information
4. **Returns** a structured summary with participants, action items, and insights

## What You'll Learn

- How to create an agent by talking to Scout (our AI assistant)
- How to configure agents with code execution tools
- How to build workflows that connect triggers to agents
- How to set up webhooks to trigger workflows from external services

## Prerequisites

Before starting, make sure you have:

- A ScoutOS account (sign up at [scoutagent.ai](https://scoutagent.ai))
- Basic familiarity with the ScoutOS interface

> **Note:** This course uses a demo transcript service. In production, you'd connect to your actual transcription provider (like Gong, Fireflies, etc.).

## Time to Complete

This course takes about **15 minutes** to complete. Each step has a video you can watch, followed by instructions to do it yourself.
